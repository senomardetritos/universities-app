# Universities App
### Descrição

Projeto front-end desenvolvido com Vue 3 em que filtrado por país carrega uma lista de universidades da api [http://universities.hipolabs.com/](http://universities.hipolabs.com/). É possível filtrar pelo nome, adicionar como favorito, ver a lista dos favoritos e mostrar uma descrição caso uma api simples desenvolvida em PHP consiga acessar o site e trazer a tag meta description. Baseado no [Template](https://www.figma.com/design/rET9F2CeUEJdiVN7JRu993/E-commerce---capputeeno) E-commerce - capputeeno, este projeto tem como objetivo treinar os conhecimentos do Vue e gestão de estado utilizando o Pinia.

Você pode acessar em: [http://senomalabs.com/universities-app](http://senomalabs.com/universities-app)
